## Documentation Principles

- Maintain consistency between SQL queries and documented findings.
- Use validated analysis results as the source of truth for reporting.
- Document business definitions and analytical limitations.
- Preserve transparency in AI-assisted reporting.
- Review documentation whenever project logic or results change.
